# Data Structures and Algorithms (DSA)

Este projeto reúne implementações de estruturas de dados (como listas, pilhas, filas, árvores e grafos) e algoritmos fundamentais. O objetivo é servir como um repositório de consulta e prática de programação, com código devidamente documentado e ambiente preparado para execução direta via GitHub Codespaces.
